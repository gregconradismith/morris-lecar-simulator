Try this in class

  1. Choose Type I below onset, then slow firing. Use the near-rest phase view to find the bottleneck where the nullclines nearly touch.
  2. For Type I, increase I from 40 to 45 µA/cm². The firing rate rises from a very low value.
  3. Compare Type II at I = 88 and 90 µA/cm². Repetitive firing starts at a finite frequency; the near-onset orbit already has a substantial period-to-period rate.
  4. Choose Type II depolarization block at I = 250 µA/cm². After the transient, compare the stable depolarized equilibrium with repetitive firing at I = 100 µA/cm².
  5. Pause and click either side of a nullcline. Predict the initial direction. A nullcline intersection is an equilibrium; its stability matters.
  6. Choose Type I below onset (I = 39 µA/cm²), then enable the saddle manifolds. The stable manifold is the local separatrix: nearby trajectories on opposite sides can have different excursions. The unstable branches leave the saddle in forward time.
Model & parameters

The reduced Morris–Lecar model describes membrane voltage V (mV) and potassium activation w (dimensionless, 0–1). Calcium activation is assumed to equilibrate instantaneously: m=m∞(V). An applied current density Iapp (µA/cm²) drives the membrane.

Membrane and recovery equations

CdVdt=Iapp−gCam∞(V)(V−ECa)−gKw(V−EK)−gL(V−EL)
dwdt=w∞(V)−wτw(V)

The three ionic terms are calcium, potassium, and leak current densities (µA/cm²). Each is a conductance density multiplied by its driving voltage. The potassium gate relaxes toward its voltage-dependent steady state.

Steady-state activation

m∞(V)=1+tanh(V−V1V2)2
w∞(V)=1+tanh(V−V3V4)2

The potassium relaxation time is τw(V)=1φcosh(V−V32V4) (ms). The parameters V1 and V3 set half-activation voltages; V2 and V4 set activation slopes.

Numerical simulation

Integration uses fourth-order Runge–Kutta with Δt=0.05 ms. Default initial conditions are V(0)=−60 mV and w(0)=w∞(−60). Clicking the phase plane chooses a new initial state. Playback speed changes the rate of model time, while the integration step remains fixed.

Changing applied current preserves the evolving state and recorded history; changing another model parameter restarts the trajectory. Trace windows span 50–10,000 ms; CSV export contains the visible time window. Nullclines and equilibrium markers use the current parameter values.

See Chapter 14 of Cellular Biophysics and Modeling and the references below for the model’s derivation and phase-plane interpretation.
