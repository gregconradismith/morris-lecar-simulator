Try this in class

  1. Choose Type I below onset, then slow firing. Use the near-rest phase view to find the bottleneck where the nullclines nearly touch.
  2. For Type I, increase I from 40 to 45. The firing rate rises from a very low value.
  3. Compare Type II at I = 88 and 90. Repetitive firing starts at a finite frequency; the near-onset orbit already has a substantial period-to-period rate.
  4. Pause and click either side of a nullcline. Predict the initial direction. A nullcline intersection is an equilibrium; its stability matters.
Model & parameters

Reduced, two-variable model: calcium activation is instantaneous, m = m∞(V).

C dV/dt = I − gCa m∞(V)(V − ECa) − gK w(V − EK) − gL(V − EL)

dw/dt = φ cosh[(V − V₃)/(2V₄)] [w∞(V) − w]

m∞ = [1 + tanh((V − V₁)/V₂)]/2; w∞ = [1 + tanh((V − V₃)/V₄)]/2.

C = 20 µF/cm²; ECa = 120, EK = −84, EL = −60 mV; V₁ = −1.2, V₂ = 18, V₃ and V₄ are adjustable; Type II defaults: V₃ = 2, V₄ = 30 mV. Type I: gCa = 4, V₃ = 12, V₄ = 17.4, φ = 0.067. Conductances: mS/cm². φ: ms⁻¹.

RK4, Δt = 0.05 ms. Initial V = −60 mV, w = w∞(−60). Trace window: 500 or 2,000 ms. CSV contains the visible window.
